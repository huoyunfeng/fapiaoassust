发票报销核对助手 · 90 秒演示（v3）
=====================================

文件
  demo_showcase.html   演示主文件（双击打开）
  qr.png               第 7 幕的微信二维码
  README.txt           本说明

打开方式
  双击 demo_showcase.html（Chrome / Edge）

操作
  空格        暂停 / 继续
  ← / →       上一幕 / 下一幕
  i           显示 / 隐藏“所在页面”等标注（现场讲解用）
  R           重新播放
  ?scene=N    直接定格到第 N 幕，例如 demo_showcase.html?scene=4

本版改动
  1. 时长调整为 90 秒（原来实际只有 75 秒）
  2. 3,180 元 = 4 类确定性问题；连号、缺日期单独列为“风险提示”，不计金额
  3. 结尾增加“免费跑一次（限 5 家）”CTA，并内置微信二维码
  4. 增加“本地部署 · 数据不上传 · 断网也能用”
  5. “10 分钟”改为“半天（含复核）”，与“节省 2.5 天”对得上
  6. “中石化朝阳加油站”改为“某某加油站（朝阳店）”
  7. 标注层默认隐藏，按 i 显示

二维码
  第 7 幕已内置 qr.png；如需更换，直接替换同名文件即可。
  发客户前建议用手机扫一次，确认能加到你。

发客户前必做
  如需发微信 / 闲鱼，建议录屏导出 MP4（手机微信打不开本地 HTML）。

截图
